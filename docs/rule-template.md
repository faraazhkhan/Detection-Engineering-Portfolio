# Rule write-up template

Copy this structure for each new rule.

- **Title and ATT&CK mapping**
- **Log source and required fields**
- **What it detects** (one or two sentences, plain language)
- **Detection logic** (what the rule matches and why)
- **How to test** (the simulated technique and where to run it safely)
- **Expected false positives and tuning**
- **Limitations** (how an attacker could avoid it)
- **Validation results** (date, tool, and a sample of the matching event)
